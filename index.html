隐私政策

本页依据当前天记 iOS／Android 工程及已知服务流程编写，覆盖本地手帐与可能启用的社交聊天功能。

待核实草稿，尚不能用于商店提交。发布主体、客服渠道、聊天服务的数据保存和删除规则尚未取得。页面不代表这些事项已经完成核验；正式运营方确认后须更新本页，并与应用内披露及商店数据声明保持一致。

1. 适用范围与运营方

天记的应用标识为 com.packageboom.tianji。应用启动时会读取远程配置：配置启用时展示社交聊天网页，未启用时展示本地手帐、计划和放松角。实际发布／运营主体及社交聊天网页的运营主体均待确认；因此目前无法准确列出个人信息处理者的名称和联系方式。

2. 本地手帐、计划与备份

您输入的手帐文字、心情、标签、照片、待办、习惯和打卡记录保存在设备的应用数据目录。待办提醒由设备本地通知处理。应用本身不会为了这些本地功能而要求您登录聊天账号。

您可在应用内修改或删除本地记录。主动导出的完整 JSON 备份可能包含文字、计划与照片，文件未加密，保存位置由您在系统界面选择；导出后请自行保护并在保存位置删除不再需要的副本。主动分享文字摘要时，接收应用和分享对象由您选择，摘要不包含照片。导入备份时，应用会按记录 ID 合并本地资料。

3. 在线图片与外部网页

当本地首页显示放松角或您主动换图时，应用向 Lorem Picsum 请求风景图。请求不包含手帐、照片、待办或习惯内容，但图片服务可能收到 IP 地址等常规网络请求信息。只有您点击摄影师链接时，才会打开相应的 Unsplash 页面。两项外部服务各自的数据处理规则应由其运营方提供。

4. 社交聊天与推送

远程配置启用社交聊天时，应用通过 iOS WKWebView 或 Android WebView 加载 HTTPS 聊天网页。登录标识、聊天内容和附件会由该网页及其后端处理，网页也可能在 WebView 中保留登录状态。当前已知原生壳会将登录 uid 作为 OneSignal 的 external ID，以便关联消息推送；推送链路还涉及 Apple APNs 或 Google Firebase Cloud Messaging。聊天附件仅在您选择下载时写入系统相册、下载目录或应用对应的“文件”目录。

聊天网页的具体运营方、完整数据类别、服务器位置、保留期限、共享对象、跨境传输与删除流程尚未取得并核实。这些事项必须由实际运营方补齐，不能根据本地壳代码推断。当前页面也不能据此声明“没有收集数据”。

5. 权限与您的选择

您拍照、选照片、保存聊天媒体或启用提醒时，系统可能分别请求相机、相册或通知权限。拒绝某项权限会影响对应功能；已授予的权限可在设备设置中管理。社交聊天账号和远程推送的数据控制、撤回同意及删除方式仍需实际运营方确认。

6. 保存、删除与联系

本地记录留在设备上，直到您在应用内删除、清除应用数据或卸载应用；您另行导出的备份不会随应用内删除自动消失。聊天账号、消息、附件及推送标识的服务端保留期限与删除步骤待运营方提供。如果聊天网页允许创建账号，正式产品还需提供实际可用的应用内删除入口和公开网页删除申请入口。

公开客服邮箱和实际运营主体联系方式待提供。在这些渠道可用前，请勿将此草稿作为正式隐私政策使用。当前状态见支持与删除。

7. 更新

正式运营方确认信息后，将更新本页内容和日期。涉及数据处理方式的变化，应在相应功能启用前按适用规则告知用户。
